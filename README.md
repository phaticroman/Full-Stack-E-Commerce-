# Full-Stack-E-Commerce-

Tech Stack: ASP.NET Core 8, C#, EF Core, Clean Architecture, CQRS, Cortex Mediator, Identity, SQL Server, Docker, AWS S3
Designed and built an enterprise-grade e-commerce platform using Clean Architecture and CQRS pattern with Cortex Mediator to ensure strict separation of concerns, scalability, and testability.
Implemented a dynamic product catalog featuring server-side pagination, multi-criteria filtering (Category, Price range, Size, Color).
Engineered a secure customer shopping workflow including a session/database-backed shopping cart, variant management (SKU, stock, size, color), and a product review/rating system.
Configured custom ASP.NET Core Identity authentication and authorization with role-based access control (Admin/Customer), custom cookie redirection, and automated email confirmation tokens.
Integrated enterprise security and storage solutions, including Google reCAPTCHA v3 for bot protection, anti-forgery tokens (CSRF prevention), and AWS S3 for media asset hosting.
Containerized the application with a multi-stage Docker Compose setup and managed deployment pipelines on cloud hosting.
